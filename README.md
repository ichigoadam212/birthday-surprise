# Birthday Surprise — Menna Allah

A small Arabic birthday greeting website made especially for Menna Allah.

## Preview locally
Open `index.html` in a browser.

## Files
- `index.html` — page structure and Arabic birthday message
- `style.css` — responsive styling and layout
- `script.js` — greeting modal and birthday confetti interaction

The page uses remotely hosted Unsplash photos and Google Fonts, so an internet connection is needed for those assets.
